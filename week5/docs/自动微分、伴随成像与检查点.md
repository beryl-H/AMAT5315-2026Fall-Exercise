# 自动微分、伴随成像与检查点

这份笔记来自 AMAT5315 Week 5 的实际计算练习：先对 Lennard–Jones 势求导，再对二维声波传播求速度敏感性，最后用 checkpointing 减少反向计算保存的历史。课程不在现有 Projects Index 中，因此 project 留空；它是通用学习概念，不属于材料样品的实验结论。

## 先建立直觉

把模拟看成一台机器：输入地下速度分布 c，输出接收器记录 F(c)。**Forward simulation** 问“给定 c，会记录到什么波形？”；**derivative** 问“如果某些位置的速度稍有改变，记录如何改变？”；**adjoint** 问“接收器的一组权重反传回来，哪些速度位置对它们最敏感？”

这些问题涉及计算图、线性化和转置，不要求显式生成巨大 Jacobian。自动微分（automatic differentiation, AD）沿程序实际执行的运算应用链式法则；它求的是离散程序的导数。程序离散误差、物理模型错误和观测范围不足仍需另外检查。

## 1. 小例子：Lennard–Jones 计算图

使用 reduced units，令 epsilon=sigma=1：

\[
a=r^{-6},\quad b=a^2,\quad c=b-a,\quad U=4c.
\]

这里的中间变量 c 只是计算图节点，**不是后面的声速 c**。

Forward mode 令输入 tangent 为 dr=1，按正向顺序传播：

\[
da=-6r^{-7}dr,\quad db=2a\,da,\quad dc=db-da,\quad dU=4dc.
\]

Reverse mode 令输出 adjoint 为 bar(U)=1，反向把贡献累加给每个输入。因为 a 同时进入 b 和 c，bar(a) 必须用 `+=` 累积两个分支，不能覆盖其中一个。

在 r=1.3，U=-0.6570169144600472，dU/dr≈2.239979929791143。物理径向力是 **-dU/dr**；正的能量导数对应负方向的吸引力，不能把 dU/dr 的图直接标成 force。

有限差分（finite difference, FD）用两次附近的函数值估计导数，含截断误差与相消误差。AD 不需要选择 h，但仍有浮点舍入误差。练习的 601 个点上，手写 forward/reverse 最大绝对误差约 2.84e-14，h=1e-6 的中心 FD 约 4.66e-9。这是本次实现的数值证据，不是所有问题的通用误差保证。

## 2. Jacobian 的两种乘积

令 J=∂F/∂c，m=δc 是一个指定的速度扰动：

\[
Jm=\left.\frac{d}{d\varepsilon}F(c+\varepsilon m)\right|_{\varepsilon=0}.
\]

这是 **Jacobian-vector product (JVP)**：给定一条输入方向，得到输出变化方向。它不等于有限幅度的完整非线性差值 F(c+m)-F(c)，只有一阶近似关系。

给定接收器权重 w，**vector-Jacobian product (VJP)** 得到 Jᵀw。若目标函数是 `1/2 ||F(c)-d_obs||²`，则 w=F(c)-d_obs，梯度为 Jᵀw。权重与方向可以独立选择，不应只用 w=Jm 验证实现。

Forward mode 适合少量输入方向的敏感性；reverse mode 适合少量标量目标对许多参数的梯度。优劣取决于输入／输出维度与程序结构，不是 reverse 永远更好。

## 3. 声波方程与离散状态

练习的阻尼声波方程可写为：

\[
\partial_t^2u+2\sigma\partial_tu=c^2\nabla^2u+q.
\]

| 符号 | 含义 | 单位 |
| --- | --- | --- |
| u | 压力样的波场 | 本练习为任意幅度单位 U |
| c | 波速 | 长度／时间 |
| sigma | sponge damping 系数 | 1／时间 |
| q | 震源项 | U／时间² |
| dx, dt | 空间网格、时间步长 | 长度、时间 |
| m | velocity perturbation δc | 与 c 相同 |

对时间使用中心差分、对空间使用二维五点 Laplacian，整理得：

\[
u_{n+1}=\frac{2u_n-(1-\sigma\Delta t)u_{n-1}
+\Delta t^2(c^2\Delta_hu_n+q_n)}{1+\sigma\Delta t}.
\]

分母来自阻尼项的时间中心差分；漏掉分母会改变传播与导数。外边界固定为零；sponge 用近边界的阻尼吸收向外传播的波，减少人为反射。它不是本练习真实地下反射层的一部分。

二维正方网格的该显式 stencil 采用 `max(c)*dt/dx <= 1/sqrt(2)` 的 CFL 限制。不稳定时，AD 仍可能忠实地对一个不稳定程序求导，因此要先验证传播器。

Reflector 的单位换算：长度单位 100 m、时间单位 0.1 s；dx=1 为 100 m，dt=0.2 为 0.02 s，c=1.8 为 1.8 km/s。Marmousi 的 dx=0.25 为 25 m，dt=0.03 为 0.003 s，source_frequency=0.5 为 5 Hz。数组按 `[z,x]` 排列，图中深度向下增加。

## 4. Born modelling 与 reverse-time migration

这里的 **Born modelling** 是波传播对 velocity perturbation 的一阶线性化。它不是量子力学里的 Born–Oppenheimer 近似。

离散 timestep 同时依赖 state 和 c。给定初始 tangent 为零，每一步对 state 方向和 m 做 JVP，再在 receivers 取样，得到 d=Jm。由于系数为 c²，而活动参数为 c，局部微分含 `δ(c²)=2cδc`；若用 squared slowness 作参数，导数需要重新定义。

RTM（reverse-time migration）将 d 作为反传权重：接收器权重先注入输出状态的 current-field adjoint，再做局部 timestep VJP。重复 receiver 的贡献要累加。速度的 adjoint 累积到最终 image：

\[
\mathrm{image}=J^Td=J^TJm.
\]

**为什么导数正确，图像却不像 m？** 因为 Jᵀ通常不是 J 的逆。有限震源频带、有限接收孔径、传播照明和离散网格使 JᵀJ 具有模糊、方向选择、幅值变化与 side lobes。真实反演还需目标函数、正则化和迭代求解，不能把 raw image 直接当成精确地下模型。

## 5. 如何确认导数与转置正确

两类互补证据：

1. **方向有限差分**：比较 Jm 与 `[F(c+h m)-F(c-h m)]/(2h)`。选择小模型、随机 m，并检查适当 h。本次独立测试的相对误差门限为 1e-7。
2. **点积／转置检验**：对独立随机 m、w，比较 `<Jm,w>` 和 `<m,Jᵀw>`。本练习是 unweighted Euclidean sums；若物理内积含 dx、dt 权重，转置定义也要随之改变。

只做第二类测试不充分：如果 J 和 Jᵀ都误乘相同常数，点积仍可相等。还要检查边界 adjoint、重复 receiver、多炮累加、输入参数化与真实 FD。

本次 reflector 的 d·d 与 m·image 约为 0.03484789，相对差达到浮点舍入量级；深度 profile 峰值位于 z=21（2.1 km）。这些证明本组离散测试一致，不能证明所有地质模型或现实观测都被正确描述。

## 6. 为什么一个 checkpoint 必须保存两个场

模拟使用二阶时间递推，所以完整重启状态是：

\[
s_n=(u_{n-1},u_n).
\]

只保存 u_n，无法唯一确定下一步。把历史变量纳入状态后，递推才成为一阶 Markov 更新 `s_{n+1}=Φ_n(s_n,c)`。还需知道步号 n，以重建确定性的 q_n；本练习没有需要额外保存的随机源或 PML auxiliary fields。

一个 float64 状态的大小为 `2*nx*nz*8` bytes。Marmousi 的 805×269 网格每状态为 3,464,720 bytes；6 个状态为 20,788,320 bytes。若完整保留 1,201 个时间状态，单是这些场就需 4,161,128,720 bytes。

这些数字不包括 replay workspace、adjoints、model、data、action log、AD scratch，也不是整个进程内存。换成更复杂物理模型时，必须重新列出全部可重启状态，不能机械套用“两个场”。

## 7. Checkpointing 的时间—存储交换

Reverse mode 需要较早的 primal state。**Checkpointing** 只保存少数状态，缺少的中间状态从最近可用 checkpoint 重新做 forward simulation。

本练习的 Treeverse 预算 δ 表示**初始状态之外**的额外槽，故 δ=5 的总峰值是 6 个状态。调度动作：

| 动作 | 含义 |
| --- | --- |
| restore | 把已保存状态复制到独立 replay workspace |
| call | 从输入步 n 做 primal，得到 n+1；只重放，不累计 image |
| store | 保存 workspace 的完整状态 |
| grad | 使用 saved slot 的输入状态做 VJP，累计 adjoint/image |
| fetch | 释放该调度槽；永久保留状态 0 |

`fetch` 是运行中释放程序自有的内存槽，不是删除用户的文件。Reverse 步必须是 `N-1,...,0`，各一次。重放过很多次的 forward 步并不意味着可以重复累加反向图像。

Reflector 的 δ=1/3/5/10 分别需每炮 28,680/1,695/990/642 个 primal forward steps，完整历史为 240。更多保存槽减少重算。四种预算的最终图像与完整历史逐位相同，并通过动作重放审计，这比只比较最终图像更能说明预算和调度正确。

## 8. 本次 Marmousi 的证据边界

实际 raw image L2 约 6.70377406e-4；δ=5 保留 6 个完整状态，符合讲义参考。图像的 x=8–14 km、上部 3 km 区域可看到倾斜条带。深部较弱，绘图使用统一的幅度色标，没有 depth gain。

“norm 与参考一致”和“条带位置接近输入”是数值再现证据；不代表恢复所有断层、不代表解决实际地震反演，也不能把 side lobes 解释成新层位。

## 易错点与复用检查

- 将 energy derivative 与 force、velocity 与 squared slowness 混淆。
- 对重复 receiver 用覆盖赋值，或者漏掉计算图多分支的 adjoint 累加。
- 把记录用 float32 展示帧当成 float64 重启状态。
- 检查的是计划中的槽数，而不是执行时实际保存的状态。
- 重放时重复累计 adjoint/image。
- 把点积一致误当成物理模型或反问题唯一性的证明。
- 更改 dt、网格、内积权重、边界或 source 后，沿用旧的参考数值。
