# Week 10: Approximate tensor contraction for the Ising model

Authoritative task: Jin-Guo Liu and Xi-Wei Pan, `week10-learning-sheet.pdf` (15 pages), SHA256 `d053e28083dce7e199e3a866e65e9da05d78a231614425d2b3c78dbacfbb1e60`.

Compute partition functions without sampling spin configurations, then locate the square-lattice zero-field Ising transition from finite-size specific-heat peaks. Use Rust f64 numerical solvers and independent saved-data checks. All temperatures use J=kB=1, K=1/T, H=-sum_edges s_i*s_j, s_i=±1.

1. Generate a 512×512 iid standard-normal matrix in Rust with seed2026, record the generator, save full matrix/spectrum/reconstructions at ranks16,64,128,256,512. Independently measure relative Frobenius error; require agreement with the spectrum-tail prediction within1e-8 and full-rank error<1e-8. Plot spectrum and errors, factor-storage break-even χ256 and 10% crossing in `artifacts/svd.png`.
2. Implement Algorithms3–4 boundary-MPS on an open square. W has rows [sqrt(coshK), ±sqrt(sinhK)], A[r,u,l,d]=sum_s W[s,r]W[s,u]W[s,l]W[s,d], missing bonds attach b=[1/sqrt(coshK),0]. Right-canonicalize with exact SVD, left-truncate to χ, scale the last core only and accumulate logarithms. Explicit CLI method,l,k,chi,out; save model/geometry/logZ/g/timing/cores/scales/truncation diagnostics. Install and run L64 K.45 χ16. Scan L16,32,64 at χ16, K.40:.0025:.50 inclusive. Around each nearest peak-grid point retain nine .00125-spaced samples at χ16 and32. Use three-point parabolas on central-difference cV=K²g'' to get Kpeak, then Tpeak=1/Kpeak. Fit Tpeak=Tc+a/L at χ32 using all sizes and largest two. Repeat the wider-step estimate using every other refined χ32 sample. Require rank and step peak shifts<1%, both Tc errors<1% vs2/log(1+sqrt2). Exact open4 at K0,.44,.7 g error<1e-8; cV at .44,h.0025 vsK²Var(H)/16 within1e-3. Save `artifacts/boundary-critical.png`.
3. Port square TRG splits/regrouping from BackwardsLinalg.jl revision b16273a2d695fef31334085e40f9e0341a1ec0f0 examples/trg.jl. Equal leg dimensions, two diagonal SVDs; C-order pair flattening; four-factor ring contraction. Normalize maxabs(A) before each step and add Nlogc, halve N after each step, use2log2L steps. Final closure is sum_ij A[i,j,i,j]. Save every split, spectrum, scale and final tensor. Reinstall and run L1024 K.44 χ16. Repeat the scan/refinement/extrapolation for periodic L64,256,1024; save `artifacts/trg-critical.png`. Periodic enumeration at .44: L2χ16 g error<1e-8, L4χ8<2e-3; L2 curvature-vs-variance error<1e-3. Count both distinct parallel positive-direction bonds at L2.

Preserve full precision in raw evidence and g/timing tables, peak-fit stencils, small checks and refinement comparison tables. Keep all generated data/tensors/figures/archives local and ignored by Git. Commit source/design/comparison scripts/documentation and push to the existing exercise repository.
