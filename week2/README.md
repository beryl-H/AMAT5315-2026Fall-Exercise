# Week 2 — Molecular Dynamics (`md`)

A small Lennard-Jones MD simulation in Rust: velocity-Verlet and Euler
integrators, cell-list forces, RDF analysis, trajectory I/O, and a CLI.

```bash
make reproduce   # runs the default 100-atom LJ-fluid trajectory
cargo test       # unit + CLI tests
```
